# ПЛЮС Вектор

Браузерний векторний редактор для шкільного офісного пакета.

## Можливості

- SVG-полотно без бекенду.
- Інструменти: вибір, олівець, лінія, стрілка, прямокутник, еліпс, трикутник, ромб, зірка, текст.
- Переміщення, виділення, зміна розміру і редагування тексту.
- Контур, заливка, товщина, прозорість і розмір шрифту.
- Підкладка: немає, сітка, рядки.
- Прив'язка до сітки.
- Undo / redo, дублювання, видалення і порядок об'єктів.
- Панель «Об'єкти»: список від переднього плану до заднього, назви, «Вище» / «Нижче», приховування й блокування (зберігаються у файлі проєкту, undo/redo і чернетці).
- Збереження проєкту в JSON (`format: art-vector-project`, `version: 2`); файли без цього поля відкриваються як legacy, файли версії 1 — без змін.
- Експорт у SVG та PNG.
- Імпорт SVG обмеженої підмножини («Файл → Імпортувати SVG…»): прямокутники, кола, еліпси, лінії, ламані, багатокутники, контури з прямих відрізків (`M`, `L`, `H`, `V`, `Z`), текст, групи й вкладені `transform`, `viewBox`, стилі з атрибутів, `style` і класів `<style>`. Після підтвердження зі списком втрат малюнок замінюється одним кроком undo.
- Багатокутник (`polygon`) — об'єкт із довільними вершинами для імпортованих замкнених контурів; переміщується, змінює розмір і заливку, як олівець. Окремого інструмента малювання немає.
- Друк і автозбереження чернетки в IndexedDB (з м'яким fallback на localStorage).

## Безпека імпорту

Project-файл вважається недовіреним. Перед потраплянням у стан він проходить
`js/project-io.js`: ліміт розміру файла, allowlist типів об'єктів, межі кількості
об'єктів і точок, clamp координат та розміру полотна, санітизація кольорів
(лише hex або `none`) і довжини тексту. Сцена й SVG-експорт будуються вузлами
DOM (`createElementNS` + `setAttribute`/`textContent`), тому значення з файла не
можуть стати розміткою.

SVG теж недовірений (`js/svg-import.js`). Файл розбирається `DOMParser` як окремий
XML-документ і в живий DOM не потрапляє: скрипти не виконуються, ресурси не
завантажуються. Файл відхиляється цілком, якщо містить `<script>`, `<foreignObject>`,
`<handler>`, `iframe`/`embed`/`object`/`audio`/`video`, атрибути `on*`, `javascript:`,
зовнішні `href` чи `url(...)`, `@import`, `<?xml-stylesheet?>`, DTD із сутностями або
зовнішнім DTD (стандартне `<!DOCTYPE svg PUBLIC "-//W3C//DTD SVG 1.1//EN" …>` без
внутрішньої частини допускається), а також якщо перевищує 5 МБ, 20 000 елементів,
64 рівні вкладеності, 32 перетворення в одному `transform` чи межі проєкту (2000
об'єктів, 4000 точок у фігурі, 60 000 точок загалом). Непідтримане — криві й дуги,
`<use>`, `<image>`, градієнти (замінюються першим кольором), маски, фільтри,
`clip-path`, анімація, повернутий текст, шрифти — пропускається або спрощується з
точним попередженням. Результат проходить ту саму нормалізацію, що й project-файл;
помилка не змінює поточний малюнок.

## Гарячі клавіші

- `V` — вибір
- `P` — олівець
- `L` — лінія
- `A` — стрілка
- `R` — прямокутник
- `O` — еліпс
- `D` — ромб
- `S` — зірка
- `T` — текст
- `Ctrl+Z` / `Ctrl+Y` — скасувати / повернути
- `Ctrl+D` — дублювати
- `Ctrl+C` / `Ctrl+V` — копіювати / вставити
- `Ctrl+S` — зберегти проєкт
- `Ctrl+Shift+S` — експортувати PNG
- `Delete` / `Backspace` — видалити
