# ПЛЮС Вектор

Браузерний векторний редактор для шкільного офісного пакета.

## Можливості

- SVG-полотно без бекенду.
- Інструменти: вибір, олівець, лінія, стрілка, прямокутник, еліпс, трикутник, ромб, зірка, текст.
- Переміщення, виділення, зміна розміру і редагування тексту.
- Контур, заливка, товщина, прозорість і розмір шрифту.
- Підкладка: немає, сітка, рядки.
- Прив'язка до сітки.
- Undo / redo, дублювання, видалення і порядок шарів.
- Збереження проєкту в JSON (`format: art-vector-project`); файли без цього поля відкриваються як legacy.
- Експорт у SVG та PNG.
- Друк і автозбереження чернетки в IndexedDB (з м'яким fallback на localStorage).

## Безпека імпорту

Project-файл вважається недовіреним. Перед потраплянням у стан він проходить
`js/project-io.js`: ліміт розміру файла, allowlist типів об'єктів, межі кількості
об'єктів і точок, clamp координат та розміру полотна, санітизація кольорів
(лише hex або `none`) і довжини тексту. Сцена й SVG-експорт будуються вузлами
DOM (`createElementNS` + `setAttribute`/`textContent`), тому значення з файла не
можуть стати розміткою.

## Гарячі клавіші

- `V` — вибір
- `P` — олівець
- `L` — лінія
- `A` — стрілка
- `R` — прямокутник
- `O` — еліпс
- `D` — ромб
- `S` — зірка
- `T` — текст
- `Ctrl+Z` / `Ctrl+Y` — скасувати / повернути
- `Ctrl+D` — дублювати
- `Ctrl+C` / `Ctrl+V` — копіювати / вставити
- `Ctrl+S` — зберегти проєкт
- `Ctrl+Shift+S` — експортувати PNG
- `Delete` / `Backspace` — видалити
