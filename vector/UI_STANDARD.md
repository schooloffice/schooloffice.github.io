# UI_STANDARD.md — ПЛЮС Вектор

До `760px` полотно займає всю ширину робочого рядка, tool rail переходить униз у горизонтальну смугу, а панель властивостей закрита за замовчуванням і відкривається поверх полотна як drawer.

Статус: локальний довідник редактора.

Глобальні правила дивись у `../UI_INTEGRATION_GUIDE.md` та `../OFFICE_UI_STANDARD.md`.
Архітектурну межу між shared root-шаром і локальним шаром редактора дивись у `../ARCHITECTURE.md`.

## Специфіка

- Тип: векторний графічний редактор.
- Основні сценарії: створення фігур, редагування контурів, текст, експорт SVG/PNG, збереження JSON-проєкту.
- Розкладка (спільна з `paint/`): верх — лише header + головне меню; ліва **tool rail** 72px (несе клас `office-toolbar`) + контекстна **properties panel** 232px, яку можна згорнути; далі workspace з артбордом; зум і «вмістити у вікно» — у статус-смузі.
- Rail містить п'ять груп: Вибір, Олівець, Лінія, Фігури, Текст. Конкретний підінструмент (яка саме фігура; лінія чи стрілка) вибирається інлайн у панелі параметрів; floating tool-пікерів немає.
- Кнопка групи запам'ятовує останній обраний підінструмент, а її іконка й заголовок секції показують активний вибір.
- Секції панелі контекстні: «Фігура» — лише для фігур, «Лінія» — для ліній, «Розмір тексту» — для тексту, «Об'єкт» — лише за наявності виділення.
- Швидкі дії save/undo/redo — компактними іконками в header; `data-office-command` маркери лишаються в прихованому `command-proxies`.
- **Об'єкти.** Кнопка «Об'єкти» внизу rail (і «Перегляд → Панель «Об'єкти»») перемикає ту саму панель у режим списку: параметри інструмента ховаються, список займає висоту панелі й прокручується сам. На вузькому екрані це той самий drawer.
  - Рядки йдуть від переднього плану до заднього. Кожен має кнопку видимості й кнопку блокування (`aria-pressed`) та назву; клік по назві вибирає об'єкт.
  - Під списком «Вище» / «Нижче» (крок у z-порядку) і «Назва…» — звичайні кнопки, доступні з клавіатури. Вимкнена кнопка передає фокус рядку вибраного об'єкта.
  - Нові об'єкти отримують назву «Прямокутник 3» тощо; старі файли без назви показуються з типовою назвою за порядком.
  - Прихований об'єкт не малюється, не ловить кліків і не потрапляє в SVG/PNG/друк. Заблокований видно й експортується, але полотно його не «чіпляє» (`pointer-events: none`), рамка виділення без ручок, а Delete, стиль, текст і розмір його не змінюють. Порядок, назву, видимість і блокування можна змінити лише в панелі.
  - Копія (дублювання, вставлення) — новий видимий незаблокований об'єкт.
  - Це «Об'єкти», а не шари: контейнерів із груповою видимістю немає.
- Меню: Файл, Редагування, Вставка, Формат, Перегляд, Допомога.
- Standard commands мають іти через command adapter.

## Локальні пріоритети

- Не дублювати toggle/listener для одного `data-action`.
- Boot має відбуватися рівно один раз: не покладатися на значення, яке повертає `OfficeShell.bootEditor`.
- Масштаб задавати шириною SVG (`--zoom` × `--canvas-width`), а не `transform: scale()` — інакше layout-розмір не змінюється і смуги прокрутки лишаються після «вмістити у вікно».
- Полотно обмежене висотою вікна: не додавати горизонтальних смуг над workspace.
- File picker має йти через `OfficeUI.openFilePicker`.
- Контекстні властивості об'єкта не мають перетворювати панель на важкий ribbon.

## Локальна структура

- `vector/index.html` — HTML shell редактора.
- `vector/style.css` — локальні стилі редактора.
- `vector/js/runtime.js` — стабільний runtime entrypoint без бізнес-логіки.
- `vector/js/app.js` — boot і shell-adapter (`VectorApp.boot`).
- `vector/js/state.js` — локальний runtime state.
- `vector/js/ui.js` — DOM/UI-шар редактора.
- `vector/js/editor.js` — доменна логіка векторного редактора.
- `vector/js/project-io.js` — валідація й нормалізація недовіреного project-файлу.
- `vector/js/storage.js` — чернетка в IndexedDB із fallback на localStorage.
- `vector/js/constants.js`, `vector/js/utils.js` — допоміжні модулі редактора.
