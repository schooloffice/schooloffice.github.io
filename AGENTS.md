# Інструкція для агента

Репозиторій `schooloffice.github.io` є самостійним проєктом Офіс ПЛЮС. Старе обмеження працювати лише в підкаталозі `office/` більше не актуальне.

Перед роботою прочитай:

- `PROMPT_FOR_AGENT.md`
- `PROJECT_DIRECTION.md`
- `README.md`
- документацію редактора, якого стосується завдання

Працюй у межах цього репозиторію, зберігай shared shell і продуктову мету локального шкільного пакета редакторів. Офлайн-режим лишається метою продукту, але тимчасово відкладений до завершення базової функціональності редакторів — не відновлюй Service Worker і precache без окремого рішення (див. розділ «Офлайн» у `PROJECT_DIRECTION.md`).
